晴天主题 UI 完整提示词

在现有邮件管理系统中实现清新、通透、安静的晴天主题。天空具有写实的云层体积和自然日光，界面保持简洁、易读，天气装饰与业务内容协调共存。保留原有功能、导航、表单、数据和主题切换行为。

一、界面与配色
以天蓝、杏黄、薄荷绿为主色。页面底色使用 #eff6fb，卡片以白色为主，正文使用深蓝灰 #20344c，辅助文字使用 #4c5d70，主交互色使用 #1f62a9。顶部场景区域从浅天蓝 #e0f3ff、清透蓝 #c9e8fc，过渡到淡绿 #e6efde 和暖杏黄 #ffe8af。卡片采用柔和圆角、细边框和轻阴影；统计信息使用青蓝、薄荷绿、紫色与珊瑚色辅助区分。保持留白、文字层级和操作区域清晰。

二、真实云层
保留具有体积感的积云。使用大小错落、位置不规则的云团构建三维密度场，叠加粗、中、细三种尺度的噪声，形成自然起伏、内部疏密和细碎边缘。模拟右上方来光与云团相互遮蔽：云顶和迎光面明亮，背光面为柔和蓝灰色，厚实区域有层次，薄薄的边缘半透明并逐渐消散。沿视线逐层累积颜色和透明度，获得轻量的体积光照效果。
生成多种云纹理并缓存，以不同大小、位置和速度缓慢漂移，保持纹理稳定。云层应有自然的空气感，不出现规则圆球拼接、硬轮廓或每帧随机闪动。

三、写实太阳
太阳位于场景右上方，中心接近白色，向边缘过渡为淡暖黄。通过细腻的亮度和透明度衰减软化轮廓，在周围叠加近处柔和辉光与范围更大的淡暖色大气散射光，让太阳呈现发光感并融入天空。
去掉均匀排列的短射线、旋转线条和边缘清晰的三角形光束。避免饱和黄圆盘、卡通图标感、夸张镜头光斑和周期性呼吸闪烁。

四、太阳与云的关系
按云纹理的实际透明度遮挡太阳和附近辉光：晴空时核心明亮，薄云经过时自然透光，厚云遮挡时明显变暗。对太阳圆盘进行多点采样，让大范围光晕的强度随云的覆盖程度平滑变化。
只在太阳附近的半透明云缘叠加克制的暖白亮边，保留厚云内部的冷色阴影与细节。光照变化由云的运动驱动，避免独立于场景的随机明暗变化。

五、动态与可读性
保留少量随风缓慢移动的浮尘，以及偶尔掠过的远处飞鸟，节奏轻缓。前景天气降低透明度，文字密集的中央区域减弱装饰。天气画布不拦截点击，不遮挡按钮、表单和数据，不造成页面布局跳动。

六、实现与性能
使用 Canvas 2D 与程序化纹理。缓存云层、薄云亮边和太阳纹理；使用可复用的 256×256 离屏画布处理太阳局部遮挡和亮边，避免逐帧重建纹理、读取整屏像素或进行整屏模糊。
兼容前台场景、后台顶部场景和页面前景天气。手机减少云与粒子数量，限制画布像素预算。支持 prefers-reduced-motion，启用时呈现静态画面；页面隐藏或场景离开视口时暂停相应动画。Canvas 不可用时，保留正常界面和操作能力。

七、验收
检查桌面与手机的晴空、薄云经过、厚云遮挡三种状态，确保太阳光照自然、云层质感稳定、文字与按钮清晰。确认主题切换不丢失表单状态，减少动态效果生效，页面没有横向溢出或脚本错误。
